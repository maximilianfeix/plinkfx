# Security

plinkfx runs entirely locally: the player renders audio in the browser, the CLI writes WAV/OGG files.
It makes no network requests and has no runtime dependencies.

If you find a security problem (for example a crafted sound file that hangs or crashes the CLI or a
browser tab), please report it privately through
[GitHub's private vulnerability reporting](https://github.com/maximilianfeix/plinkfx/security/advisories/new)
instead of a public issue. Expect a first answer within a week.

Supported: the latest released version.
